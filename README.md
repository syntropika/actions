# Syntropika Actions

Reusable GitHub Actions live in separate directories in this repository. Each directory has its own `action.yml` and documentation.

| Action | Purpose |
| --- | --- |
| [coolify-deploy](coolify-deploy/README.md) | Configure environment variables and resource settings, then deploy through the Coolify API. |

Actions are versioned together. Pin production workflows to a full commit SHA; release tags provide a convenient version reference.
